# CargoTown Landing Page

Landing page responsive para una empresa de logística y transporte internacional, desarrollada con Angular y Tailwind CSS.

## Descripción

Este proyecto recrea una interfaz moderna para una marca de carga y envíos, con secciones como:

- Hero principal
- Soluciones por transporte
- Servicios destacados
- Calculadora de costos
- Formulario de contacto
- Preguntas frecuentes
- Footer institucional

## Tecnologías

- Angular
- TypeScript
- Tailwind CSS
- HTML/CSS

## Requisitos

- Node.js
- npm
- Angular CLI

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm start
```

La aplicación estará disponible en:

```bash
http://localhost:4200
```

## Compilación para producción

```bash
npm run build
```

## Estructura principal

```bash
src/
  app/
    app.component.ts
    app.component.html
    app.component.css
  styles.css
```
